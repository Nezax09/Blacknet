# Blacknet Info

Blacknet is a script hub made by Nezax09. It currently supports 1 game.


# Games
## The Maze

- Main Tab

  - Get All Items
  - Third Person + Third Person Zoom Slider
  - Fullbright
  - Control Killers
 - Player ESP Tab
   - Names + Names Color Picker
   - Distance + Distance Color Picker
   - Chams + Chams Color Picker (Fill and Outline)
  - Monster ESP Tab
     - Names + Names Color Picker for Cajoler AND Orotund
     - Distance + Distance Color Picker for Cajoler AND Orotund
     - Chams + Chams Color Picker (Fill and Outline) for Cajoler AND Orotund
  - Player Tab

# Themes

Blacknet has something alot of other hubs dont - themes. While other hubs may use libraries to let the own player customize their themes, Rayfield isn't built with that feature. However, we have made pre-built themes to save you from the complication of having to create your own theme, with more being added every update. There are currently 4 themes for Blacknet.
